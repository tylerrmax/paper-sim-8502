# 长期路线图：ML 与宏观因子的前置条件

## 原则
**机器学习和宏观因子是放大器，不是救命稻草。**
只有传统规则策略在严格成本下证明有正期望，才值得上 ML。

## ML 特征工程的前置条件（必须全部满足）

### 1. 传统策略正期望验证
- [ ] v1.0 策略在 3 个以上不同市场状态（牛/熊/震荡）下回测为正
- [ ] 实盘模拟 3 个月，执行分 ≥90，且与回测偏差 <20%
- [ ] 严格成本：滑点 0.1%、手续费按实盘最高档、T+1

### 2. 数据基础设施
- [ ] 数据质量门禁：缺失、异常、拆股调整自动化
- [ ] 特征存储：避免训练-推理 skew
- [ ] 回测引擎支持 walk-forward（滚动训练/测试）

### 3. 过拟合防线
- [ ] 样本外测试 ≥ 样本内 30% 时长
- [ ] 特征重要性稳定（跨时间段 top 特征重合度 >60%）
- [ ] 简单模型（逻辑回归）先行，复杂模型需显著优于简单模型

## 宏观/情绪因子的定位

### 定位：过滤层，不是信号层
- 宏观因子（利率、信用利差、VIX）→ 决定仓位上限（risk-on/risk-off）
- 情绪因子（涨跌家数、融资余额）→ 决定是否暂停新开仓
- 不直接生成买卖信号，只做"刹车"

### 候选因子
1. **宏观**：中美利差、信用利差、美元指数
2. **情绪**：A股涨跌家数比、融资余额变化、VIX
3. **周期**：库存周期位置（OECD领先指标）

### 接入方式
- 每日更新一次（低频）
- 输出三态：risk_on（正常）、neutral（减半）、risk_off（只平仓不开仓）
- 与市场状态识别（趋势/震荡）正交，取最保守者

## 时间表（意向）
- 2026Q4：完成中期四项，v1.0 实盘验证
- 2027Q1：若 v1.0 达标，启动 ML 可行性研究（单因子测试）
- 2027Q2：宏观因子过滤层上线（先影子运行，不实际干预）
- 2027H2：视前两项效果，决定 ML 是否进入生产

## 红线
- 任何时候，ML 模型的仓位占比 ≤ 传统策略的 50%
- 宏观 risk_off 时，ML 信号自动降权 50%
- 每月人工复核 ML 信号，不可完全黑箱

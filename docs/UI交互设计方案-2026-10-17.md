# 8502 UI交互设计方案（2026-10-17）

> 状态：方案待确认，未实施。用户确认后按阶段执行。

## 一、设计原则

1. **交易终端，而非资讯站**：参考同花顺/富途/TradingView，密度高、信息全、操作短
2. **闭环优先**：每个页面都知道"我从哪来、到哪去"，搜索→选股→验证→交付→兑现→回执不断线
3. **一屏一事**：每个tab只解决一个核心问题，不堆砌
4. **中文名优先**：所有标的显示`代码+中文名`，账户显示`A股/港股/加密货币`
5. **零学习成本**：按钮文字即动作（"复制条件单"而非"导出"）

## 二、导航重构（7→5）

### 现状问题
- 7个tab太多，"市场全景"与"行情与信号"职能重叠
- "系统与审计"用户几乎不看

### 提案：5个tab
| # | Tab | 职能 | 对应闭环步骤 |
|---|-----|------|--------------|
| 1 | 🏠 工作台 | 今日待办+风险警报+闭环入口 | 总览 |
| 2 | 🔍 选股 | 搜索+TradingView/新浪/东财三源K线+关注+技术形态 | 搜索→选股→验证 |
| 3 | 📝 交易 | 待建条件单（一键复制）+回执录入+事件流 | 交付→兑现→回执 |
| 4 | 💰 账户 | 三账户净值+持仓+资金流+成交明细 | 复盘 |
| 5 | 🛡 验证 | 毕业KPI+策略规则+回测报告 | 验证 |

- "市场全景"并入"选股"（技术形态是选股的依据，不独立）
- "系统与审计"折叠进工作台底部（或仅管理员可见）

## 三、核心交互详设

### 3.1 选股页（新）
```
[搜索框：输入代码/拼音]  [行情源：TV/新浪/东财]
[TradingView K线图 500px]
[⭐关注] [📋加入待验证]
[技术形态卡片]
  RSI 28.9(超卖) | ADX 35.8(趋势) | MACD -0.166(空头)
  布林：8.71/7.95/7.19 | 均线：空头排列
  [✅加入条件单候选]
[我的关注] 横向卡片，一键切换
```

### 3.2 交易页（改造）
**待建条件单**每条改为卡片式：
```
┌─────────────────────────────┐
│ 002446 盛路通信  BUY          │
│ 数量 7200股  参考价 6.94      │
│ 策略：接回 | 信号日 10-15     │
│ [📋复制] [✅已建单] [⏭跳过]   │
└─────────────────────────────┘
```
- 📋复制：一键复制`002446 盛路通信 买入7200股 限价6.94`，去同花顺粘贴
- ✅已建单：标记后进入"待回执"状态
- ⏭跳过：记录跳过原因，永不补成交

**回执录入**：扫码/粘贴交割单自动解析（预留，先手动）

### 3.3 工作台（改造）
```
[闭环进度条] 搜索→选股→验证→交付→兑现→回执（当前高亮）
[今日待办]
  ☐ 2条待建条件单未处理
  ☐ 1条待回执
[风险警报]
[三账户迷你卡] 点击展开资金流（已实现）
```

### 3.4 账户页（改造）
- 三账户改为**标签页**（不是并排卡片），手机端更友好
- 每个账户内：净值曲线（文字 sparkline）+ 持仓表 + 资金流 + 成交明细
- 增加"导出对账单"（CSV）

### 3.5 验证页（保持）
- 毕业KPI记分牌保留
- 增加"策略对比"：v1.0 vs draft 的回测曲线对比

## 四、视觉规范

- 深色主题（已实现，保持）
- 涨跌色：A股红涨绿跌、港股/加密同（用户习惯）
- 数字字体：等宽，右对齐
- 主按钮：蓝色；危险：红色；成功：绿色
- 卡片圆角 8px，间距 12px

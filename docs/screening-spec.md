# 选股三重校验规格（量化技术面 × X博主新闻面 × 母板板块共振）

目的：辅助交易、控制风险。**宁缺毋滥**——三层全部通过才输出；任何一层缺输入、过期或存疑，一律不放行。

## 结论状态
| 状态 | 含义 |
|---|---|
| 过关 PASS | 三层全部通过，附风险卡（止损/数量/风险金额） |
| 否决 VETO | 有可验证的利空（带公告/链接佐证） |
| 待校验 WAIT | 量化层已过，但新闻/板块输入缺失、过期、格式错误，或存在未核实利空 |
| 未过关 FAIL | 系统硬门槛未过（先判，风控优先）或某层不达标 |

合并优先级：系统硬门槛 → 新闻否决 → 技术面不达标 → 某层 FAIL → 某层 WAIT → PASS。
因硬门槛优先，A股当前因仓位已超上限而全部显示「未过关」，而不是「待校验」，这是有意设计。

## 第一层 量化技术面（复用系统校验）
硬门槛：K线≥60根；行情陈旧≤3天；非 display_only；账户策略未停用；系统买入校验通过且可买数量>0
（含仓位上限）；最新信号未过期、非待执行卖出；非涨跌停日。
技术：趋势(±1)+动量(±1)≥+1；RSI≤70；%B≤0.95；5日涨幅≤15%。

## 第二层 新闻/市场面（muse 每日简报）
输入 `screen_inputs/briefs.json`：
```json
{"asof":"2026-10-23","items":[{"date":"2026-10-23","source":"博主名","target":"002446 或 板块名",
  "direction":"利好|利空|中性","event_type":"公告","fact":"一句话事实","evidence":"公告/链接（可空）"}]}
```
规则（有效期 3 个交易日）：可验证利空→否决；未核实利空→待校验；
利好需「有佐证」或「≥2 个独立来源」；单源无佐证→不足以确认。主题/板块简报通过板块名/别名命中成分股。

## 第三层 母板板块共振
输入 `screen_inputs/sector_board.json`：
```json
{"asof":"2026-10-23","sectors":[{"name":"商业航天","aliases":[],"members":["002446"],
  "rank_pct":85,"ret_5d":3.0,"ret_20d":6.0,"breadth":0.7}]}
```
规则：强度百分位≥70；板块5日涨幅>0；上涨家数占比≥50%（有则校验）；个股20日涨幅不低于板块−5个百分点。
标的未映射到任何板块→待校验。

## 风险卡（仅过关标的）
止损=现价−2×ATR14；数量=min(系统建议数量, 净值×单笔风险%/每股风险)，按手数取整。

## 配置与限制
阈值可由 `config/strategy.yaml` 的 `screen:` 覆盖（键见 `engine/screener.py` DEFAULTS）。
交易日按周一至周五计，不含节假日。示例文件 `*.example.json` 不会被加载。
A股成交量存在单位异常，故不使用量能因子。

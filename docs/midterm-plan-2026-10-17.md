# 中期规划：仓位管理与过滤机制（2026-10-17，按截图要求）

## 1. 统一风险预算与波动率目标仓位（Volatility Targeting）

### 核心原则
不再使用固定金额或固定百分比下单，而是根据资产历史波动率（Volatility）动态调整持仓权重，实现"**高波动缩仓，低波动加仓**"，使得各资产对组合的风险贡献均衡。

### 公式
```
资产权重 = (目标波动率 / 资产历史波动率) × 基准权重
资产历史波动率 = ATR(14) / 收盘价 × √250（年化）
```

### 示例
- 组合目标波动率：15% 年化
- A股某标的年化波动 25% → 权重系数 0.6
- 港股某标的年化波动 35% → 权重系数 0.43
- BTC 年化波动 70% → 权重系数 0.21

### 风险预算三层
1. 组合层：总风险预算 6%（月度最大回撤）
2. 策略层：buyback 40% / ma20-港股 30% / ma20-加密 30%
3. 标的层：单笔风险 ≤2%（ATR止损距离 × 仓位）

## 2. 市场状态识别（Trend vs Range-bound）

### 过滤层指标
- **ADX（平均趋向指标）**：核心指标
- **均线多头排列度**：MA10>MA20>MA30 为多头排列

### 震荡市保护机制（截图明确要求）
**当 ADX < 20 时，认定为震荡市，暂停突破/趋势跟踪策略**，避免在震荡行情中被频繁"拉锯擦伤"（Whipsaw）。

### 具体规则
| ADX | 状态 | MA策略 | Buyback策略 |
|-----|------|--------|-------------|
| >25 | 趋势市 | 正常执行 | 正常执行 |
| 20-25 | 过渡 | 仓位减半 | 正常执行 |
| <20 | 震荡市 | **暂停新信号** | 正常执行（均值回归在震荡市更有效） |

### 实现
- 新增 `engine/indicators.py`：ADX(14)、布林带宽、排列度
- 每日收盘计算，写入 market_data 或独立表
- 状态切换不清仓，只影响新信号

## 3. 构建多策略组合（Portfolio Management）

### 目标组合
将单一策略扩展为"**趋势跟踪 + 均值回归 + 波动率突破**"的多策略组合，通过低相关性策略互相平滑资金曲线。

### 策略池
| 策略 | 类型 | 当前状态 |
|------|------|----------|
| ma20 | 趋势跟踪 | 已上线（sim_hk/sim_crypto） |
| buyback | 均值回归 | 已上线（sim_a） |
| breakout | 波动率突破 | 待开发（中期） |

### 权重分配
- 基于历史夏普比率的逆波动率加权
- 每月再平衡一次
- 策略间相关性 >0.7 时，降低合计权重

### 实施步骤
1. 为每个策略生成独立信号序列（已具备）
2. 计算策略组合净值（加权平均）
3. 回测组合 vs 单策略，验证分散效果

## 实施优先级
1. **市场状态识别**（最直接减少 Whipsaw 亏损）
2. **波动率目标仓位**（平滑收益曲线）
3. **统一风险预算**（体系化）
4. **多策略组合**（需 breakout 策略开发完成）
